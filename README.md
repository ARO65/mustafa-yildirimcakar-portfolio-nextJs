# Mustafa Portfolio
Next.js portfolio + client request portal scaffold inspired by the architectural discipline of EasyGoingEducation.

## Included
- App Router, Server Components by default
- GitHub project service with 1-hour revalidation
- PrimeReact Featured Projects carousel
- SCSS Modules with component/style collocation
- React `useActionState` project request form
- Server Action + Yup + normalized helper responses
- `revalidatePath`, loading/error/not-found, metadata, sitemap, robots
- Dashboard/request route skeleton ready for NextAuth/proxy authorization

## Run
npm install
npm run dev

Set `GITHUB_USER=ARO65` and `NEXT_PUBLIC_SITE_URL` in `.env.local` as needed.
